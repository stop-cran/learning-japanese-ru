# 戸 — дверь; счётное слово для домов

**Черты:** 4 · **Ключ (радикал):** 戶 (№ 63) · **JLPT:** N2 (общественный учебный список)

## Значение и происхождение

戸 связано с дверью, а также используется при счёте домов или домохозяйств. 戸（と）— исконное существительное со значением «дверь». 一戸（いっこ）— один дом или одно домохозяйство; этот пример показывает счётное чтение コ.

**Мнемоника по современному начертанию, не этимология:** представьте верхнюю черту над нижним контуром, похожим на дверь, — дверную панель под перекладиной. Это мнемоника по современной форме, а не утверждение об историческом происхождении.

Канонический радикал в источнике — 戶 (№ 63). В карточке используется современная японская форма 戸; сохраняйте канонические метаданные, не подменяя радикал другим.

## Примечания

- В 一戸 いっこ есть маленькая っ. Статья [戸](../../../../words/戸.md) разбирает существительное «дверь» с чтением と, а не отдельное чтение こ этого существительного.
- Счёт с 戸 относится к домам или домохозяйствам, а не к отдельным дверным полотнам.
- В 雨戸 あまど исконное と озвончается до ど; это не онное чтение コ.
- В 瀬戸物 せともの знак 戸 читается と в составе названия места 瀬戸 (Сэто). Название изделия не означает буквально «дверные вещи».
- Сравните с [戻](../../../../kanji/戻.md) («возвращаться; отменять»): у него есть дополнительные нижние черты.

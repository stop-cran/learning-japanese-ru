# 復 — восстанавливать; повторять

**Черты:** 12 · **Ключ (радикал):** 彳 (№ 60) · **JLPT:** N2 (общественный учебный список)

## Значение и происхождение

復 связано с возвращением к прежнему состоянию и повторением действия. 回復（かいふく）— восстановление, а 復習（ふくしゅう）— повторение уже изученного материала. Значение целого слова не означает, что 復 следует каждый раз переводить одним и тем же глаголом.

**Мнемоника по современному начертанию, не этимология:** представьте 彳 рядом с составной правой частью, заканчивающейся на 夂, идущим по уже пройденному пути. Это образ для запоминания современной формы, а не этимология.

## Примечания

- Написание 復 для また в JMdict помечено как редкое; обычно это слово пишут каной. Сохраняйте его для узнавания, а не как рекомендацию заменять обычное また этим кандзи.

# 掃 — подметать; смахивать щёткой

**Черты:** 11 · **Ключ (радикал):** 手 (№ 64) · **JLPT:** N2 (общественный учебный список)

## Значение и происхождение

掃 связано с подметанием и смахиванием чего-либо. 掃く はく — глагол «подметать», а 掃除 そうじ обозначает уборку в более широком смысле. Сам знак не означает, что при любой уборке 掃除 обязательно пользуются метлой.

**Мнемоника по современному начертанию, не этимология:** обратите внимание на 扌 рядом с правой частью, заканчивающейся 巾, и представьте руку, которая двигает уборочный инструмент. Это мнемоника по современной форме, а не проверенное объяснение происхождения знака.

Канонический ключ — 手; здесь он виден в левой форме 扌.

# 旧 — прежний; бывший; старый

**Черты:** 5 · **Ключ (радикал):** 日 (№ 72) · **JLPT:** N2 (общественный учебный список)

## Значение и происхождение

旧 связано с тем, что было раньше: с прежним, бывшим или относящимся к прошлому. В роли приставки 旧 きゅう указывает на прежнее название, здание, систему или версию. Исконные чтения — отдельные значения из словаря знаков; это не способ читать каждое слово с 旧.

**Мнемоника по современному начертанию, не этимология:** обратите внимание на вертикальную черту рядом с 日 и представьте отметку дня, который уже прошёл. Это мнемоника по современной форме, а не историческое объяснение.

## Примечания

- JMdict помечает 旧い как редкое написание прилагательного [古い](../words/古い.md) ふるい. Сохраняйте его для узнавания, а не вместо обычного написания 古い.
- В словах с 旧 в роли приставки используется чтение きゅう. Строка もと фиксирует другое чтение из словаря знаков; общая форма написания не означает, что каждый пример читается как もと.
- [新](新.md) («новый») — полезное противопоставление. Прежнее здание не обязательно обветшало: прежний статус и физическое состояние — разные понятия.

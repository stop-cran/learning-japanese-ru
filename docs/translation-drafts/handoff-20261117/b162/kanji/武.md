# 武 — военный; воин

**Черты:** 8 · **Ключ (радикал):** 止 (№ 77) · **JLPT:** N2 (общественный учебный список)

## Значение и происхождение

武 связано с военным делом и воинской тематикой. 武器 ぶき — оружие, 武士 ぶし — воин или самурай, 武者 むしゃ — воин. Необычное нативное прилагательное 武し たけし сохранено для распознавания с пометой об архаичности.

**Мнемоника по современному начертанию, не этимология:** Обратите внимание на пересекающиеся верхние черты и нижнюю часть, похожую на 止, и представьте воинскую эмблему. Это мнемоника по современной форме, а не историческое объяснение знака.

## Примечания

- 武し たけし — архаичное прилагательное типа ку. JMdict также указывает 猛し в этой статье. Это контекст для распознавания, а не рекомендация для обычной современной речи.
- В словарной статье 武士 рассматривается чтение ぶし и исторический контекст воинов. Не выводите произношение каждого слова о воинах из чтения ブ: в 武者 используется ム.
- 止 — канонический радикал для индексации. Мнемоника не доказывает историческое утверждение, будто 武 буквально означает прекращение войны.

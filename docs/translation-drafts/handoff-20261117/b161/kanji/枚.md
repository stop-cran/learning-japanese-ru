# 枚 — счётный суффикс для плоских предметов

**Черты:** 8 · **Ключ (радикал):** 木 (№ 75) · **JLPT:** N2 (общественный учебный список)

## Значение и происхождение

枚 — счётное слово, которое ставят после числа для тонких плоских предметов: например, листов бумаги, тарелок или монет. 二枚 にまい — два таких предмета. В счёте употребляется чтение マイ; отдельный пример с чтением バイ относится к архаичному выражению.

**Мнемоника по современному начертанию, не этимология:** 木 рядом с 攵 — представьте, как пересчитывают стопку плоских деревянных предметов, постукивая по ней. Это мнемоника по современной форме, а не подтверждённое объяснение происхождения знака.

## Чтения

| Чтение | Тип | Примеры слов |

| マイ | он | 二枚 にまい — два листа; два плоских предмета; 枚数 まいすう — количество листов или других плоских предметов |
| バイ | он | 枚を含む ばいをふくむ — «затыкать рот лошади» (архаичное выражение) |

## Частые слова

- 枚 まい — счётное слово для тонких плоских предметов
- 二枚 にまい — два листа; два плоских предмета
- 枚数 まいすう — количество листов или других плоских предметов

## Примечания

- Используйте 一枚 いちまい, 二枚 にまい и 三枚 さんまい. В счёте чтение マイ не превращается в バイ.
- JMdict прямо помечает 枚を含む ばいをふくむ как архаичное выражение. Здесь оно сохранено для иллюстрации указанного в источнике чтения バイ, а не как образец обычной речи или альтернативный способ счёта.
- Этим счётным словом считают не только бумагу. При этом физическая тонкость предмета не отменяет установившихся счётных слов: например, для переплетённых книг используется 冊 さつ.

# 板 — доска; плоская пластина

**Черты:** 8 · **Ключ (радикал):** 木 (№ 75) · **JLPT:** N2 (общественный учебный список)

## Значение и происхождение

板 обозначает доску, планку или плоскую пластину материала. いた может быть деревянной доской или стеклянной панелью; 黒板 こくばん — школьная доска. Знак не ограничен изделиями из дерева.

**Мнемоника по современному начертанию, не этимология:** 木 рядом с 反 — представьте, как переворачивают деревянную доску. Это мнемоника по современной форме, а не этимология.

## Частые слова

- 板 いた — доска; планка
- 黒板 こくばん — школьная доска
- 看板 かんばん — вывеска; репутация заведения

## Примечания

- JMdict перечисляет 板木 はんぎ наряду с 版木 はんぎ для деревянной печатной формы. Это пример для узнавания чтения ハン; сам список написаний не позволяет судить об их частотности.
- Тем же написанием 板木 записывается отдельное слово ばんぎ — деревянная доска, по которой ударяют как по сигнальному инструменту. Это не слово для печатной формы выше.
- Исконное существительное 板 читается いた. В приведённых примерах 黒板 こくばん и 板木 はんぎ иллюстрируют чтения バン и ハン; произношение зависит от целого слова и его значения.
- Сопоставьте с [坂](../kanji/坂.md) «склон»: слева у него 土, а не 木.

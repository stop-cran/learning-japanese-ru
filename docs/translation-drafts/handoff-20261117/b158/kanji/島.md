# 島 — остров

**Черты:** 10 · **Ключ (радикал):** 山 (№ 46) · **JLPT:** N2 (список сообщества)

## Значение и происхождение

島 означает остров. 孤島 ことう — уединённый остров; 半島 はんとう — полуостров, то есть не полностью отделённая суша. Изучайте целое слово, а не считайте, что 島 в каждом слове обозначает отдельный остров.

**Мнемоника по современной форме, не этимология:** Заметьте похожую на птицу верхнюю часть над 山 и представьте птицу, смотрящую на остров-гору. Это зрительная подсказка для запоминания, а не историческое объяснение знака.

## Примечания

- В сложном слове собственное чтение может озвончаться: 小島 こじま означает «небольшой остров». Это не значит, что 島 в каждом имени читается じま.
- Сравните с [鳥](鳥.md) «птица» и [山](山.md) «гора»: ни один из этих знаков сам по себе не означает «остров».

# 見当（けんとう）— прикидка; примерное представление

## Значение

見当 — существительное со значением «прикидка, догадка, примерное представление». Две полезные конструкции: **見当がつく**, «иметь представление», и **見当をつける**, «прикинуть». Отрицание 見当がつかない значит «не имею представления».

- いくらかかるか見当がつきません。（いくらかかるかけんとうがつきません。）— Понятия не имею, сколько это будет стоить.
- 食事代は一人三千円見当です。（しょくじだいはひとりさんぜんえんけんとうです。）— Еда обойдётся примерно в три тысячи иен на человека.

Во втором примере 見当 — суффикс после суммы со значением «примерно». Он не обещает точную цену.

## Как сочетаются кандзи

[見](../kanji/見.md) вносит значение «смотреть, оценивать»; [当](../kanji/当.md) — «попадать, совпадать с целью». Как подсказку для запоминания можно представить оценку того, где находится цель. Слово читается ケン + トウ; эта подсказка не историческое происхождение.

## Синонимы и антонимы

[予想](予想.md)（よそう）— предсказание, ожидание. [およそ](およそ.md) может выражать приблизительное количество. 検討, тоже けんとう, значит «рассмотрение, изучение» — это другое слово.

## Оттенки значения

見当 само по себе не значит «найтись». Для этого есть глагол [見つかる](見つかる.md). Учите 見当 вместе с конструкцией: представление, которого нет в 見当がつかない, может касаться места, стоимости или объяснения, а не потерянной вещи.

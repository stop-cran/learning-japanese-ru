# 足りる（たりる） — хватать; быть достаточным

## Значение

足りる означает, что имеющееся количество
покрывает потребность: «хватать», «быть достаточным».
Это непереходный глагол второй группы:
足ります, 足りない, 足りて.
Ресурс, достаточность которого оценивается,
оформляется частицей が.

- 時間が足りません。（じかんがたりません。）— Времени не хватает.
- 千円で足りますか。（せんえんでたりますか。）— Тысячи иен хватит?

## Как сочетаются кандзи

[足](../kanji/足.md) передаёт た,
а りる — окуригана.
Здесь у знака значение достаточности,
а не чтение あし, «нога».
Основа для форм вроде 足ります — たり.

## Синонимы и антонимы

[十分](十分.md)（じゅうぶん）означает «достаточный».
不足する（ふそくする）— «недоставать», «испытывать нехватку».
足す — переходный глагол «добавлять»:
такое действие может восполнить недостающее.

## Оттенки значения

が выделяет имеющийся ресурс.
で может обозначать количество или средство,
достаточное для конкретной цели.
足りる не утверждает, что чего-то много само по себе:
для небольшой задачи может хватить малого количества.

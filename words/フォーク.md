# フォーク — вилка

## Значение

フォーク — вилка, прежде всего столовый прибор для еды.
Чтобы указать её как инструмент, с помощью которого едят, используется で.

- フォークでサラダを食べます。 (フォークでサラダをたべます。) — Я ем салат вилкой.
- フォークを一本ください。 (フォークをいっぽんください。) — Дайте, пожалуйста, одну вилку.

Во втором примере для счёта одного тонкого прибора используется 本 (ほん) в форме 一本 (いっぽん).

## Как сочетаются кандзи

Заимствование из английского пишется катаканой.
Маленькая ォ соединяется с フ и образует フォ, а ー удлиняет гласный: フォーク.
Компонентов-кандзи нет.

## Синонимы и антонимы

[ナイフ](ナイフ.md), «нож», режет еду; スプーン, «ложка», зачерпывает её.
箸 (はし), «палочки для еды», — ещё один столовый прибор.
Это полезные сопоставления при сервировке, а не антонимы.

## Оттенки значения

Для нескольких вилок японское слово не получает окончания множественного числа.
В бейсболе フォーク бывает сокращением フォークボール, «форкбол», — названия одной из подач.
Это отдельное употребление, а не значение столового прибора в данных примерах.

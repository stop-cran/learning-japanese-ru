# 出口（でぐち）— выход

## Значение

出口 — путь наружу: выход из здания, со станции или с автомагистрали; переносно — выход из затруднения.

- 出口はこちらです。（でぐちはこちらです。）— Выход в этой стороне.
- 駅の出口はどこですか。（えきのでぐちはどこですか。）— Где выход со станции?
- トンネルの出口が見えます。（とんねるのでぐちがみえます。）— Виден выход из туннеля.
- 出口が見えません。（でぐちがみえません。）— Я не вижу выхода. Переносно: не вижу выхода из ситуации.

## Как сочетаются кандзи

[出](../kanji/出.md) — «выходить», で — и [口](../kanji/口.md) — «отверстие», ぐち, с озвончением в сочетании: «отверстие, через которое выходят». Сравните противопоставленное [入口](入口.md).

## Синонимы и антонимы

- Противопоставление: 入口（いりぐち）— вход.
- Родственные слова: [出入口](出入口.md) — один проход, используемый в обе стороны; 非常口（ひじょうぐち）— аварийный выход; 改札口（かいさつぐち）— проход для проверки билетов.
- Для выхода из затруднения: 解決策（かいけつさく）— решение; 活路（かつろ）— выход, путь спасения, литературное слово.

## Оттенки значения

При нескольких выходах указатели различают их по месту или назначению: 東口（ひがしぐち）— восточный выход; 非常口 — аварийный выход. Переносно 出口 и 入口 образуют пару: выход из ситуации и путь в неё.

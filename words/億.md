# 億（おく）— сто миллионов

## Значение

億 — числовая единица 100 000 000, сто миллионов.
В японском большие числа группируются по степеням десяти тысяч:
один 億 равен десяти тысячам 万.

Для ста миллионов обычно говорят
一億（いちおく）,
для двухсот миллионов — 二億（におく）.

この建物は一億円です。（このたてものはいちおくえんです。）— Это здание стоит сто миллионов иен.

## Как сочетаются кандзи

億 — один кандзи с онным чтением おく.
Он используется как часть числа,
а не как счётный суффикс для определённого вида предметов.

## Синонимы и антонимы

万（まん）— десять тысяч.
一千万（いっせんまん）— десять миллионов,
то есть одна десятая 一億.

Десять единиц 億 образуют 十億（じゅうおく）—
один миллиард.
Не смешивайте эти числовые разряды.

## Оттенки значения

億 нельзя переводить как «миллион».
В денежных суммах название валюты
ставится после полного числа:
三億円（さんおくえん）— триста миллионов иен.

Для количества людей добавляется 人:
一億人（いちおくにん）— сто миллионов человек.
Значение числа сохраняется;
меняется то, что этим числом считают.

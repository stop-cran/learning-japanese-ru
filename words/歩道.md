# 歩道（ほどう）— тротуар; пешеходная дорожка

## Значение

歩道 — тротуар или дорожка для пешеходов. Это существительное, которое называет место для ходьбы.

- 歩道を歩いてください。（ほどうをあるいてください。）— Идите, пожалуйста, по тротуару.
- この道には歩道がありません。（このみちにはほどうがありません。）— На этой дороге нет тротуара.

В первом предложении を отмечает путь, по которому идут, а не предмет, который пешеход изменяет. に во втором предложении указывает, где тротуара нет.

## Как сочетаются кандзи

[歩](../kanji/歩.md) вносит значение «ходить пешком», а [道](../kanji/道.md) — «дорога, путь». Первый знак уточняет назначение второго: «путь для ходьбы». Онные чтения: ホ + ドウ.

## Синонимы и антонимы

車道（しゃどう）— часть дороги для транспорта; это полезное противопоставление при описании улицы. [道](道.md)（みち）«дорога; путь» — более широкое слово, которое само не говорит, есть ли отдельная пешеходная часть.

## Оттенки значения

歩道 относится к дорожке для пешеходов, а не к материалу, которым покрыта дорога. Само слово не определяет все местные правила движения и не говорит, можно ли ехать по конкретному участку на велосипеде; это сообщают знаки и местные правила.

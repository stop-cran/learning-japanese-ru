# テープ — лента; клейкая лента

## Значение

テープ — лента. По контексту различают клейкую ленту для закрепления предметов,
ленту для записи и другие похожие полосы материала.

- 箱をテープでとめました。 (はこをテープでとめました。) — Я закрепил коробку скотчем.
- このテープには昔の歌が入っています。 (このテープにはむかしのうたがはいっています。) — На этой ленте записаны песни прошлых лет.

В первом примере で отмечает материал для закрепления,
а во втором テープ называет носитель записи.

## Как сочетаются кандзи

Слово заимствовано из английского tape, «лента», и записано катаканой.
Знак ー удлиняет гласный в テ; это часть написания, а не пунктуационный знак,
разделяющий два слова.

## Синонимы и антонимы

セロハンテープ — именно целлофановая клейкая лента.
カセットテープ — кассетная лента для записи.
Слово カセット обозначает кассету, а также может означать игровой картридж.
Эти более узкие названия помогают уточнить, какой вид имеется в виду.

## Оттенки значения

テープ — существительное, само по себе не действие «заклеивать лентой».
Чтобы сказать о приклеивании, используют テープを貼る (テープをはる).
Если без дополнительного контекста просят テープ, нужный вид ленты
может потребоваться уточнить по ситуации.

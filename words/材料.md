# 材料（ざいりょう）— материал; ингредиенты

## Значение

材料 — материал, из которого что-то делают, в том числе ингредиенты для готовки. Nの材料 значит
«материалы для N»; 材料にする — «использовать как материал». Слово может обозначать и сведения,
служащие основой для суждения.

- カレーの材料を買ってきました。（カレーのざいりょうをかってきました。）— Я купил ингредиенты для карри.
- この資料を判断の材料にします。（このしりょうをはんだんのざいりょうにします。）— Я использую этот документ как основание для решения.

Во втором примере 材料 употреблено в переносном смысле: никакой физический предмет не изготавливают.

## Как сочетаются кандзи

材 вносит значение «материал, пригодная древесина», а [料](../kanji/料.md) —
«материал, запасы». Близкие значения усиливают идею исходных веществ для создания чего-то. Онные
чтения: ザイ + リョウ.

## Синонимы и антонимы

[資料](資料.md)（しりょう）относится к справочным сведениям или документам. 資料 может стать 材料 для
аргумента, но ингредиенты для готовки обычно не называют 資料. Русское «материалы» в смысле
«документы, справочные сведения» обычно соответствует 資料, а не 材料.

## Оттенки значения

Спросите себя, что делают или решают. В кулинарии 材料 — ингредиенты, в строительстве —
стройматериалы, при принятии решения — значимые сведения. Слово не значит «любое имущество» или
«любое оборудование». Кастрюля — инструмент для готовки, а не ингредиент карри.

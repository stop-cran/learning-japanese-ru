# 隻（せき）— счётное слово для судов

## Значение

隻 — счётное слово, которое вместе с числительным используется для подсчёта кораблей и лодок.
Это не обычное существительное «корабль».
一隻（いっせき）— один корабль; 二隻（にせき）— два корабля.

- 港に船が一隻あります。（みなとにふねがいっせきあります。）— В гавани стоит один корабль.
- 二隻の船が見えます。（にせきのふねがみえます。）— Я вижу два корабля.

В первом предложении сочетание числа со счётным словом стоит после 船が. Во втором 二隻の
стоит перед 船. В 一隻 запомните целое чтение いっせき, а не простое сложение いち и せき
без звукового изменения.

## Как сочетаются кандзи

Один знак 隻 записывает счётное слово онным чтением セキ.
В 一隻 [一](../kanji/一.md) даёт число «один», а 隻 — счётное слово для судов.

## Синонимы и антонимы

[船](船.md) и [舟](舟.md), оба читаются ふね, — существительные «лодка; корабль»;
они называют предмет, а не считают его.
[枚](枚.md)（まい）считает тонкие плоские предметы и не заменяет счётное слово для судов.
Другие числа меняют количество, но не дают лексической противоположности счётному слову.

## Оттенки значения

Источник фиксирует также подсчёт одной половины пары, например половины складной ширмы.
Употребление для подсчёта связок — рыб, птиц или стрел — помечено как устаревшее;
значение счётного слова для судов такой пометы не имеет.
Не переносите эту помету на каждое выражение с 隻 и не считайте знак счётным словом
для любых предметов.

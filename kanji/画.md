# 画 — изображение; черта

**Черты:** 8 · **Ключ (радикал):** 田 (№ 102) · **JLPT:** N4 (список сообщества)

## Значение и происхождение

画 связано с изображениями и нарисованными чертами. В словах о планировании оно тоже встречается: например, 計画 けいかく — «план».

**Мнемоника по современной форме:** представьте центральную часть, похожую на [田](田.md), картинкой с чертой сверху и рамкой снизу и по бокам.
Это современная подсказка, не доказанная история происхождения.

## Чтения

Чтения ниже имеют разный статус. Словарное чтение знака не означает, что оно свободно образует самостоятельное современное слово.
В метаданных сохранена выбранная классификация KANJIDIC2: エ и カイ находятся в онном разделе. Отличающаяся классификация другого словаря отмечена отдельно.

| Чтение | Тип | Слова и справочные значения |
| --- | --- | --- |
| ガ | онное | [映画](../words/映画.md) えいが — фильм; 画面 がめん — экран; изображение на экране |
| カク | онное | 計画 けいかく — план |
| エ | онное в выбранных метаданных | Справочное чтение знака из KANJIDIC2. У [漢字ペディア: 画](https://www.kanjipedia.jp/kotoba/0000737000) есть отдельное слово 画 え «изображение», но этот словарь относит え к кунным чтениям вне основного списка |
| カイ | онное, справочное | Чтение знака сохранено по KANJIDIC2; здесь не предлагается неподтверждённое слово с этим чтением. Чтение カイ у 絵 само по себе не доказывает его употребление в слове с 画 |
| えが.く | кунное | 画く えがく — рисовать; сопоставьте написание 描く |
| かく.する | кунное в выбранных метаданных | 画する かくする — разграничивать; 一線を画する いっせんをかくする — чётко отграничивать, отличать одно от другого |
| かぎ.る | кунное, справочное | В «普及版字通» для 画 приводится かぎる «ограничивать; разделять». Для сопоставления: слово 限る かぎる; его написание само по себе не подтверждает 画 |
| はかりごと | кунное, справочное | Для 画 тот же словарь приводит значение замысла, плана и историческую запись чтения ハカリゴト. Сопоставьте отдельное написание 謀 はかりごと |
| はか.る | кунное, справочное | В [漢字ペディア: 画る](https://www.kanjipedia.jp/kotoba/0000740100) есть 画る はかる — замышлять, планировать. Сопоставьте 図る／計る はかる, не считая все написания заменяемыми в любом контексте |

Справочные строки не устанавливают одинаковую современную употребительность всех чтений и не объявляют их все архаичными.

## Частые слова

- [映画](../words/映画.md) えいが — фильм; кинофильм.
- 画面 がめん — экран; изображение на экране.
- 計画 けいかく — план.

## Примечания

Чтения ガ и カク запоминайте на примерах целых слов.
Сравните простую рамку [田](田.md) и охватывающую форму [国](国.md). У 画 важны дополнительная верхняя черта и нижняя рамка.

Для самостоятельного существительного «картинка; рисунок» учите также 絵 え.
Не переносите автоматически каждое словарное чтение знака в обычную речь и не подменяйте чтение 画 чтением похожего 絵.

Справочные значения: раздел «普及版字通» в [コトバンク: 画](https://kotobank.jp/word/%E7%94%BB-456348); отдельные слова: [漢字ペディア: 画](https://www.kanjipedia.jp/kotoba/0000737000), [漢字ペディア: 画く](https://www.kanjipedia.jp/kotoba/0000737100), [漢字ペディア: 画る](https://www.kanjipedia.jp/kotoba/0000740100).

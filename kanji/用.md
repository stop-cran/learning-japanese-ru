# 用 — использование; назначение

**Черты:** 5 · **Ключ (радикал):** 用 (№ 101) · **JLPT:** N4 (список сообщества)

## Значение и происхождение

用 связан с использованием чего-либо, его назначением
или делом, требующим внимания.
[用事](../words/用事.md) — дело или поручение,
не обязательно оплачиваемая работа.

**Мнемоника современной формы:** представьте разделённый контур
как стойку с отдельными местами для полезных инструментов.
Это подсказка по современной форме, не утверждение о первоначальном изображении.

## Чтения

| Чтение | Тип | Примеры |
| --- | --- | --- |
| ヨウ | онное | [用事](../words/用事.md) ようじ — дело; 使用 しよう — использование |
| もち.いる | кунное | 用いる もちいる — использовать |

## Частые слова

- [用事](../words/用事.md) ようじ — дело; то, чем нужно заняться
- 使用 しよう — использование; применение
- 用いる もちいる — использовать

## Примечания

Сравните с [月](月.md): у 用 есть дополнительная вертикальная черта внутри.
У [田](田.md) нижняя сторона замкнута, а у 用 — нет.

Глагол читается もちいる, с отдельными ち и い.
Кандзи передаёт もち, а окуригана — いる.
